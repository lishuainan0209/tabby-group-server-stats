## 从这里开始使用底部状态栏

本手册带你从已安装插件开始，一步步控制分屏状态栏、编辑默认指标、创建单标签和标签组，再亲手配置系统盘与数据盘。示例命令在当前连接的 Linux 服务器上执行；它们不是在本机 Windows PowerShell 中运行的命令。

### 先打开正确的设置页

打开 Tabby 设置 → 底部状态栏，确认“显示底部状态栏”总开关已开启。连接一台可测试的 Linux 服务器，再回到终端分屏。1.7.6 固定使用底部栏；每个分屏左下角的小图标负责该分屏的显示和模式。

设置页右上角高亮的“教程（PDF）”会使用系统默认 PDF 程序打开本手册。界面为中文时打开中文版本，其他语言打开英文版本。PDF 的目录和左侧书签可跳转；正文中的命令可选择复制。

## 点左下角图标，控制当前分屏

### 1. 点击图标，打开竖向菜单

在终端分屏左下角点击小图标，菜单从下方按钮向上展开。它通过点击打开；把鼠标移到菜单、经过按钮与菜单之间的空隙时，菜单会保持打开。选择一个选项后关闭；点击菜单外、再次点击图标或按 Escape 也可关闭。切换终端上下文时会收起。

| 选项 | 选择后会发生什么 |
| --- | --- |
| 显示 | 显示当前分屏的底部状态栏。 |
| 隐藏 | 隐藏当前分屏的状态栏，保留左下角按钮以便恢复。 |
| 概览 | 显示当前分屏的状态栏，并让标签组使用概览模式。 |
| 轮播 | 显示当前分屏的状态栏，并让标签组轮流显示子标签。 |
| 静态 | 显示状态栏及组内全部成员；保留各组原有横排/竖排设置。 |

### 2. 试着隐藏，再恢复

选择“隐藏”，确认状态栏收起；重新点击留下的小图标，直接选择“概览”“轮播”或“静态”。选择任一模式都会自动显示当前分屏的状态栏，并一起保存显示状态与模式，无需额外点“显示”。只想恢复原模式时可选择“显示”。模式只改变标签组展示，不会把单标签改成轮播；设置页的总开关仍需开启。

### 3. 把三分屏保存为“关、关、开”

打开一个已经保存的三分屏布局，分别在前两个分屏的菜单选择“隐藏”，第三个直接选择所需模式，例如“轮播”。关闭这个布局，从配置列表重新打开：前两个继续隐藏，第三个继续显示，并保留其模式。即使三个分屏源自同一连接，也可以分别控制。

> 首次选择分屏模式前，各标签组按自己的配置展示；选择后，该分屏的模式覆盖其中各组的模式。布局关系依赖保存的布局和分屏位置；若替换或重排布局分屏，请重新检查控制结果。

## 先把默认指标调成顺手的样子

### 1. 只保留你需要的项目

在设置页的“默认指标”区域，点击“已启用/已禁用”按钮切换状态。1.7.6 的默认项目只有内存、网络、CPU 负载。禁用会保留配置；升级前自定义过的旧 CPU 或磁盘指标可能作为单标签保留，请在单标签区域检查。

### 2. 调顺序，再改外观

用每项右侧 ↑、↓ 调整默认指标顺序。点击铅笔编辑名称、图标、颜色、类型、命令和显示范围。网络和 CPU 负载是标签组，点击主标签或子标签框编辑对应成员，最后保存整个标签组。单标签可拖动排序；多标签组用 ↑、↓ 排序。

### 3. 先读懂数值，再改命令

| 默认项目 | 如何理解 |
| --- | --- |
| 内存 | 主值为使用百分比；悬停可查看可用/总容量。 |
| 网络 | 下载/上传是当前速率，单位 MB/s，保留 3 位小数。悬停的累计接收/发送从网卡建立或计数器重置起累计，并非从 SSH 登录起累计。 |
| CPU 负载 | 主值是运行中/总线程数；1min、5min 子标签是按逻辑 CPU 数归一化的负载，可超过 100%，不是 CPU 忙碌百分比。 |

网络优先使用默认路由网卡；没有可用默认路由时选择可用的非回环网卡。容器只能看到自身命名空间允许看到的网卡与统计。极小流量可能四舍五入为 0.000 MB/s，并不等于网络故障。

### 4. 改错时恢复这一项

点击该默认指标的“恢复默认”，重置该项自定义定义；它不是恢复整个插件，也不是删除你的其他标签。想暂时不用，就禁用。背景颜色、不透明度和默认更新频率在页面上方调整。

> 内置命令包含 Linux/macOS 分支，但下面的磁盘实操针对 Linux。自定义命令必须适合当前连接的操作系统；无法读取容器外的磁盘或进程时，不能仅靠显示设置解决。

## 亲手创建一个单标签

在“单标签”标题旁点击“添加单标签”，才会出现新建表单。标签填“登录会话”，类型选“文本值”，后缀留空，频率 10 秒，超时 15 秒。图标可从选择器查找用户图标；也可填写 FontAwesome 名称或上传 SVG。

### 1. 先确认 who 命令存在

```sh
command -v who >/dev/null 2>&1 && echo exists
```

把它填到“对象校验命令”。比较方式选“输出文本”，期望值填 exists，失败提示填“无 who”。输出文本会去掉首尾空白后精确比较。也可改用退出码：去掉 && echo exists，比较“退出码”，期望值填 0。不要把输出的字符 0 和退出码 0 混淆。

### 2. 填功能命令

```sh
data=$(who 2>/dev/null) || exit 1
printf '%s\n' "$data" | awk 'NF {n++} END {print n+0}'
```

### 3. 填悬停扩展信息命令

```sh
data=$(who 2>/dev/null) || exit 1
printf '%s\n' "$data" | awk '
  NF {users[$1]=1}
  END {for (u in users) {print u; n++}
       if (!n) print "No logged-in users"}'
```

保存后返回终端：常态显示登录会话数；移入单标签，在状态栏上方弹窗中查看去重的用户名，移出后收起。它显示当前 who 能看到的登录用户，不是仅显示当前 SSH 账号。同一人多次登录会产生多条会话；容器的 who 也可能为空。

> 留空对象校验会直接执行功能命令；留空扩展命令则不显示额外信息。校验失败会阻止功能命令和扩展命令执行。先在同一个 SSH 终端手动运行，确认输出，再保存到插件。

## 让数字、颜色和刷新配合起来

### 1. 让功能命令只输出需要显示的值

数值指标尽量只输出数字，把 %、GB 等单位放入“后缀”。“文本值”适合容量、人数和百分比；“进度条”还要填写最大值，例如百分比用 100。扩展信息可输出完整文字或“剩余/总量 GB”。数字按千位分隔符显示，容量各列及斜杠两侧分别对齐。

GB 沿用本插件原有的 1024³ 字节计算，仅统一显示名称；不要因为标签改成 GB 就再次除以 1000。网络 MB/s 按 1,000,000 字节/秒计算，保留 3 位小数。显示格式不会把颜色比较改成比较带逗号的字符串。

### 2. 把严重预警放在规则上方

在“条件颜色规则”点“添加规则”，选择比较符、填写阈值与颜色。第一条满足条件的规则决定颜色；都不满足时使用默认颜色。使用率升高是坏事，磁盘剩余量降低才是坏事，比较方向不同。

| 指标 | 第一条：红 #ff0000 | 第二条：橙 #ffa500 |
| --- | --- | --- |
| GPU 显存使用率 | > 80 | > 50 |
| 内存使用率 | > 80 | > 60 |
| 1min / 5min 负载 | > 150 | > 100 |
| 单盘剩余 GB | < 20 | <= 40 |
| 总剩余 GB | < 50 | <= 100 |

默认色设 #00ff00。以上使用率规则使用严格“大于”：恰好 80 不会触发 > 80。磁盘规则先红后橙，单盘恰好 20 或 40 都是橙色。不要把主标签线程数这样的“运行中/总数”文本直接当百分比设置阈值。

### 3. 区分采样频率、轮播间隔与超时

标签的“频率”决定命令采集间隔，留空时使用全局默认；组的“轮播间隔”只决定切换显示速度。超时限制单次执行等待。慢命令建议先用 20 秒频率、60 秒超时验证。悬停详情会缓存并合并重复请求，快速移入多次不代表每次都重新执行。

> “未返回数据”不必然是频率过高：也可能命令没有标准输出、工具不存在、权限不足或执行失败。先在同一连接运行原命令并检查输出和退出码，再调整时间；不要用提高频率掩盖失败。

## 把重复设备整理成标签组

### 1. 建立主标签与子标签

点击“添加标签组”，先填组名称，再填写主标签和多个子标签。每个成员都独立拥有校验、功能、扩展命令及刷新频率，整个组共用显示范围。组名称用于设置与悬停标题，底部常态显示成员名称。编辑已有组默认折叠，点击对应主标签/子标签框再展开。

| 组模式 | 先试什么 |
| --- | --- |
| 概览 | 平时只显示主标签；悬停在上方展开主标签、子标签和详情。 |
| 轮播 | 按子标签顺序轮换；悬停暂停并在上方展开全组。宽度保持稳定，跳过不参与轮播的失败子标签。 |
| 静态横排 | 主标签和子标签排成一行；移入谁就展开谁的扩展信息。 |
| 静态竖排 | 成员紧凑排列，以细线分隔；移入组后展开全体成员扩展信息。 |

如果当前分屏已在左下角菜单选择模式，它会覆盖组内模式。静态的横排/竖排仍按组设置保留。组内“轮播间隔”不改变命令执行频率。

### 2. 复制一个子标签

在组编辑器内，点击子标签右侧“复制子标签”。副本会出现在同组并获得独立身份与副本名称。修改名称、三条命令中的设备号或路径，最后保存整个标签组。复制只复制配置，不会自动发现另一张显卡或另一块磁盘。

### 3. 复制整个标签组

在组卡片右上角点击“复制标签组”，得到独立副本并进入编辑。立即检查组名、显示范围、主标签和所有子标签命令；否则原组和副本可能同时出现在同一连接。用 ↑、↓ 调整组或子标签顺序。

### 4. 暂停使用与真正删除

点击“已启用/已禁用”可保留命令和规则。组、主标签、子标签可分别控制。删除按钮与常用编辑操作分开，删除前弹出带名称的确认框；删除整组会连同成员一起删除。不要把删除当成暂时隐藏。

> 失败子标签有两个开关：“前置校验失败时显示此标签”决定所有模式是否显示；只有它开启时，“前置校验失败时仍参与轮播”才有意义。磁盘宜保留故障提示；不存在的 GPU 插槽可关闭显示。

## 把标签放到正确的连接和分屏

### 1. 从“所有窗格”改为指定范围

单标签或标签组编辑器顶部的“显示范围”默认是所有受支持终端窗格。改为“指定连接或已保存布局（可多选）”，搜索并勾选所需连接。组内所有成员共享范围；想让两台机器使用不同磁盘命令，应建立两组并分别绑定。

### 2. 展开布局，选择里面的分屏

保存的布局默认展开，下面缩进的条目是各个分屏。即使原始连接配置被删除，布局内保留的连接副本仍可在这里选择。勾选布局可全选其分屏；只想显示在一个分屏，就勾选需要的条目。

### 3. 同 ID 自动勾选，再逐个取消

勾选一个连接时，同一连接 ID 的对应条目会一起勾选，包括布局中的副本。取消勾选只取消当前条目，因此你可以先一起选中，再逐个去掉不需要的分屏。名称相同但 ID 不同的连接不会因此合并。

例如布局内有服务器 A 的两个分屏和服务器 B 的一个分屏：A 磁盘组只选择两个 A 条目，B 磁盘组选择 B 条目。然后用第 2 页的左下角按钮，独立决定每个分屏是否显示整条状态栏。范围选择和显示开关解决的是两个不同问题。

### 4. 删除配置或改布局以后检查一次

失效目标会显示“已删除或不可用”。移除或替换失效项，不会自动改成全局显示。指定范围中一个都没选时，这个标签不会出现在任何分屏；如果确实想全局显示，需主动切回“所有终端窗格”。

> 安装前已打开、或刚从当前分屏保存的布局，请从已保存配置列表重新打开一次以建立可靠布局关联。按普通连接绑定不依赖这一步。替换、增删或重排布局分屏后，再检查范围与左下角菜单的持久化选择。

## 从预设开始，再分享自己的配置

### 1. 先在预设库搜索并阅读

内置预设无需联网即可使用。在搜索框输入 GPU、磁盘等关键词，先看说明、命令预览和建议绑定连接，再点击“添加”。添加后会成为可编辑单标签或标签组，并按范围执行命令。标注“作者实验室自用”的 P0-P4 等预设只供作者实验室，其他人请勿下载使用；普通用户请按本教程创建自己的磁盘组。1.7.6 的 P3 磁盘模板使用 /、/data、/data2；已经添加过的旧组仍需核对实际路径。

### 2. 从 GitHub 获取新的预设清单

点击“从 GitHub 导入”，等待完成。来源链接指向该插件仓库 main 的预设库。此操作只加载预览，不自动更新或覆盖已添加的标签；选中条目并点击“添加”后才启用。网络失败时可继续使用内置预设，或改用 JSON 文件。

### 3. 不要通过反复添加来刷新

添加过的条目显示“已添加”，按钮不可重复点击。判断依据包括预设来源、稳定 ID，以及旧配置的命令和范围，不只看名称；改名或禁用后仍算已添加。需要恢复使用时启用原条目；需要类似设备时使用“复制标签组/子标签”，而不是重复导入。

### 4. 导入同事给你的 JSON

点击“导入 JSON”，选择有效预设库文件，阅读预览后再添加。便携绑定按连接名称重新匹配；找不到或名称有歧义时会提示并限制范围。打开新增条目的“显示范围”，亲自选对连接与布局后再使用。导入不是恢复整份 Tabby 设置。

### 5. 导出前先检查内容

点击“导出我的标签”，保存 JSON 文件。它导出自定义单标签与标签组及便携绑定名称；不包含默认指标编辑、分屏按钮选择，也不是 SSH 账号配置备份。命令文字和连接名称会进入文件，分享前检查是否写入了私人路径或令牌。

> 可先在测试配置中导入自己刚导出的文件：确认预览、重复保护与绑定提示符合预期，再提供给同事。导入清单本身不执行命令，但点击“添加”后会按配置执行。

## 从零配置一组磁盘监控

本教程带你在一个 Linux SSH 分屏里建立“磁盘演示”标签组。主标签显示系统盘与数据盘的总剩余容量；子标签分别显示系统盘 / 和数据盘 /data。把鼠标移到概览上，会看到各盘的剩余容量 / 总容量。

> 示例效果：磁盘总余量 1,240 GB；展开后可见系统盘 40 GB、/data 1,200 GB。这里是演示数据，不代表你的服务器。

### 先准备好一条 SSH 连接

在 Tabby 打开你要监控的 Linux 服务器。教程中的命令由这个连接的登录用户在服务器上执行，不是在 Windows 本机执行。先在终端手动运行，再粘贴到设置，出错时更容易找到原因。

本教程使用 Linux 的 df、awk、stat、findmnt 和 mountpoint。无需安装 Python，也不需要 sudo。示例假设 /data 是独立挂载的数据盘；如果你的挂载点不同，下一页先找出真实路径。

### 找到入口

打开 Tabby 设置 → 底部状态栏。你会看到默认指标、预设库、单标签和多标签组等区域。新配置默认提供内存、网络和 CPU 负载；这些可编辑项目与本教程创建的磁盘组互不替代。

点击多标签组旁边的“添加标签组”。填写组名称“磁盘演示”，选择“概览”，暂时保持显示范围为“所有终端窗格”。先在测试连接验收，随后第 7 页再把它限制到目标连接。

> 教程针对 1.7.6。界面打开已有标签组的“编辑”时默认折叠成员；点击“主标签”或“子标签”标题即可打开对应编辑框。新建组会展开主标签，便于开始填写。

本实操中，第 10 页确认路径，11-12 页填写主标签，13 页加入系统盘，14 页复制数据盘，15 页检查结果。显示范围与左下角菜单可随时参照第 7 页和第 2 页。

## 先找到真正的数据盘

```sh
findmnt -rn -o TARGET,SOURCE,FSTYPE
df -Pk /
mountpoint -q /data && echo exists
df -Pk /data
```

从 findmnt 的 TARGET 列找你的数据盘路径。mountpoint 命令输出 exists，才表示 /data 当前确实是一个挂载点。只有目录存在并不等于磁盘已挂载：掉盘后的空目录仍可能存在，直接 df /data 会误报它所在的系统盘。

若路径是 /mnt/data，请把本教程所有 /data 都替换为 /mnt/data，包含主标签的路径列表和子标签的三条命令。先不把 /boot/efi、临时文件系统或不需要监控的目录加入组。

### 第 2 步 · 给主标签填这些字段

| 字段 | 本例填写 |
| --- | --- |
| 标签 | 磁盘总余量 |
| 类型 / 后缀 | 文本值 / GB |
| 默认颜色 | #00ff00 |
| 频率 / 超时 | 20 秒 / 60 秒 |
| 对象校验命令 | 留空；汇总命令逐个校验每个候选盘 |

功能命令只输出数字，因此在“后缀”填写 GB。扩展信息命令自己输出“剩余/总容量 GB”，不再额外添加后缀。数字会以千位分隔符显示，例如 1,240。颜色规则仍比较原始数值。

### 先看懂三种命令的顺序

对象校验先判断盘是否可用。通过后才执行功能命令，决定平时显示的主值。悬停扩展信息在需要时提供更详细的结果。没有校验命令就直接执行；没有扩展信息命令就只显示主值。

> GB 是本插件沿用的显示名称，磁盘容量仍按 1024³ 字节计算。示例没有把数值改为十进制，因此既有数值和颜色阈值保持一致。网络速率 MB/s 则是十进制。

## 填写磁盘总剩余容量

将下面整段粘贴到主标签的功能命令。路径列表只有 / 和 /data；以后每增加一个盘，要同时更新此处和下一页扩展信息里的路径列表。

```sh
rows=$(
  for p in '/' '/data'; do
    if [ "$p" != / ]; then
      mountpoint -q -- "$p" 2>/dev/null || continue
    fi
    dev=$(stat -Lc '%d' -- "$p" 2>/dev/null) || continue
    data=$(df -Pk -- "$p" 2>/dev/null) || continue
    now=$(stat -Lc '%d' -- "$p" 2>/dev/null) || continue
    [ "$dev" = "$now" ] || continue
    if [ "$p" != / ]; then
      mountpoint -q -- "$p" 2>/dev/null || continue
    fi
    printf '%s\n' "$data" | awk -v dev="$dev" '
      NR == 2 && NF >= 6 && $2 ~ /^[0-9]+$/ &&
      $4 ~ /^[0-9]+$/ && $2 > 0 && $4 <= $2 {
        printf "%s %s %s\n", dev, $2, $4
      }'
  done
)
printf '%s\n' "$rows" | awk '
  NF == 3 && !seen[$1]++ {total += $2; free += $3; n++}
  END {
    if (!n || total <= 0) exit 1
    printf "%.0f\n", int(free / 1048576)
  }'
```

这段命令跳过未挂载或读不到的数据盘，按文件系统编号去重，避免一个盘挂载到多个路径时重复相加。最后只输出一个整数，表示所有有效盘的总剩余容量。

> 请先在终端试跑：成功时应只输出一个数字。没有任何有效盘时命令会失败，不会把错误伪装成“剩余 0”。主标签校验留空是有意的：每个候选盘已在这段命令内单独校验。

## 让概览显示更完整的容量

将下面整段放入主标签的扩展信息命令。它与上一页使用相同的路径和去重方法，但最后输出剩余 / 总容量，保留一位小数。

```sh
rows=$(
  for p in '/' '/data'; do
    if [ "$p" != / ]; then
      mountpoint -q -- "$p" 2>/dev/null || continue
    fi
    dev=$(stat -Lc '%d' -- "$p" 2>/dev/null) || continue
    data=$(df -Pk -- "$p" 2>/dev/null) || continue
    now=$(stat -Lc '%d' -- "$p" 2>/dev/null) || continue
    [ "$dev" = "$now" ] || continue
    if [ "$p" != / ]; then
      mountpoint -q -- "$p" 2>/dev/null || continue
    fi
    printf '%s\n' "$data" | awk -v dev="$dev" '
      NR == 2 && NF >= 6 && $2 ~ /^[0-9]+$/ &&
      $4 ~ /^[0-9]+$/ && $2 > 0 && $4 <= $2 {
        printf "%s %s %s\n", dev, $2, $4
      }'
  done
)
printf '%s\n' "$rows" | awk '
  NF == 3 && !seen[$1]++ {total += $2; free += $3; n++}
  END {
    if (!n || total <= 0) exit 1
    printf "%.1f/%.1f GB\n", free/1048576, total/1048576
  }'
```

比如 1,240.5/8,000.0 GB 表示当前合计可用 1,240.5、总容量 8,000.0。/ 左边是剩余量，不是已用量。数字两列分别靠右对齐，便于逐行比较。

> 功能命令和扩展信息命令必须监控相同的路径。只改其中一处，会出现主值与悬停结果对不上的情况。添加其他磁盘时，把路径加进两段 for p in 列表。

## 添加第一个子标签：系统盘

点击“添加子标签”。标签填写“系统盘”，类型选“文本值”，后缀为 GB，频率 20 秒、超时 60 秒。对象校验的比较方式选择“输出文本”，期望值填写 exists。

### 对象校验命令

```sh
test -d / && df -Pk / >/dev/null 2>&1 && echo exists
```

### 功能命令（输出系统盘剩余容量）

```sh
data=$(df -Pk -- '/' 2>/dev/null) || exit 1
printf '%s\n' "$data" | awk '
  NR == 2 && NF >= 6 && $2 ~ /^[0-9]+$/ &&
  $4 ~ /^[0-9]+$/ && $2 > 0 && $4 <= $2 {
    t=$2; a=$4; ok=1
  }
  END {if (!ok) exit 1; printf "%.0f\n",int(a/1048576)}'
```

### 悬停扩展信息命令

```sh
data=$(df -Pk -- '/' 2>/dev/null) || exit 1
printf '%s\n' "$data" | awk '
  NR == 2 && NF >= 6 && $2 ~ /^[0-9]+$/ &&
  $4 ~ /^[0-9]+$/ && $2 > 0 && $4 <= $2 {
    t=$2; a=$4; ok=1
  }
  END {if (!ok) exit 1; printf "%.1f/%.1f GB\n",a/1048576,t/1048576}'
```

将校验失败提示设为“不可用”。暂时保留“前置校验失败时仍显示”。该开关能让掉盘或读取失败被看见，而不是把对应条目静默藏起来。

> 此时先点击“保存整个标签组”，再回到 SSH 分屏验证。主标签与各子标签会一起保存。若添加按钮无法保存，检查每个成员是否都有标签或图标，以及非空的功能命令。

## 复制出数据盘，再设置预警

重新编辑“磁盘演示”。在“系统盘”子标签上使用“复制”，组内会新增一个独立副本。打开副本，把标签改成 /data；后缀、刷新频率等设置可以保留。副本不会与原标签联动修改。

### 把校验改成检查真实挂载

```sh
mountpoint -q -- /data 2>/dev/null && echo exists
```

比较方式仍用“输出文本”，期望值仍是 exists；校验失败提示改成“未挂载”。在复制出来的功能命令和扩展信息命令中，把 df -Pk -- 后面的 '/' 都改成 '/data'。不要替换算术除号。

### 两处 df 行都应变成这样

```sh
data=$(df -Pk -- '/data' 2>/dev/null) || exit 1
```

再添加 /data2 时，复制 /data 子标签，修改名称与三条命令里的路径；同时把 /data2 加入主标签两条命令的路径列表。复制整个标签组适合另一台挂载路径不同的服务器：副本需要重新核对显示范围，避免两组一起出现在同一连接。

### 让不足容量用颜色提醒你

| 编辑对象 | 第一条规则 | 第二条规则 |
| --- | --- | --- |
| 系统盘及各数据盘 | < 20 → #ff0000 | <= 40 → #ffa500 |
| 主标签：总剩余量 | < 50 → #ff0000 | <= 100 → #ffa500 |

规则从上到下，只使用第一条命中的颜色。因此必须先填红色规则，再填橙色规则。默认色保持 #00ff00。单盘等于 20 或 40 时为橙色，超过 40 为绿色；总量等于 50 或 100 时为橙色。

磁盘建议保持失败时仍显示；若不想轮播停在未挂载盘，可单独关闭“前置校验失败时仍参与轮播”。若把“仍显示”也关掉，该盘会在所有模式隐藏，也不会进入轮播。保存整个标签组后生效。

> 改盘路径时，三条子标签命令和主标签两处汇总列表都要修改。若仍见旧值，检查是否有同名旧组或副本，并核对各组的显示范围。保存会自动刷新数据，但不会替你修正旧路径或移除多余副本。

## 最后验证，再开始日常使用

### 1. 先确认数字对得上

手动运行 df -Pk / 和 df -Pk /data，核对 Available 与 1024² 的换算。等待一次刷新，再悬停比较各盘剩余/总容量。显示整数可能向下取整，而详情保留一位小数，两者出现不足 1 GB 的差异正常。

### 2. 用不存在的路径测试掉盘提示

复制 /data 子标签，临时改为 /not-a-real-mount，并修改三条命令中的路径。保存后应显示“未挂载”，而不是系统盘容量。验证后禁用或删除这个测试副本；删除确认框会显示名称，请核对后确认。不要为了测试真的卸载正在使用的磁盘。

### 3. 验证重启后的布局

在一个分屏选择隐藏，另一个选择轮播。关闭该布局并从保存的配置重新打开，检查开关和模式是否保留。若更换了布局内的分屏位置或连接副本，需要重新核对绑定。

### 遇到问题时，从这一项开始查

| 现象 | 下一步 |
| --- | --- |
| 完全没有标签 | 检查分屏是否隐藏、组是否禁用、显示范围是否选中。 |
| 显示未挂载 | 在同一 SSH 终端运行校验；核对输出文本或退出码。 |
| 有主值但没有详情 | 检查扩展命令非空，手动执行并确认有标准输出。 |
| 出现超时或错误 | 检查命令、权限与工具是否存在；再调整频率或超时。 |
| 总量比预期小 | 缺失盘会被跳过；同一文件系统只计一次。 |
| 旧值或重复标签组 | 检查同名旧组、主/子标签路径及范围；禁用多余副本。 |

校验命令不要混淆输出与退出码：mountpoint -q 本身没有成功文本。若选择“输出文本”，用 && echo exists 并比较 exists；若选择“退出码”，直接使用 mountpoint -q，期望值为 0。

不用的标签先“禁用”，可保留命令和颜色规则；删除用于真正移除。默认指标可单独恢复默认，恢复操作会清除该项自定义编辑。预设库导入只加载预览，添加后才会执行命令；作者实验室专用的 P0-P4 预设不适合直接套到其他服务器。

> 到这里，你已亲手完成一个可复制、可校验、能显示故障并能按连接绑定的磁盘组。继续添加磁盘时，按第 14 页的“三条子命令 + 两处汇总列表”检查，通常就不会漏改。
